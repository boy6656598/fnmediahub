# 需求文档 - fnnas-media-hub v2

## 1. 简介

**项目名称**: fnnas-media-hub  
**项目类型**: 私有云盘媒体中心管理系统  
**核心功能**: 登录网盘账号、添加分享链接、自动削刮海报墙、转存播放一体化、STRM文件管理  
**目标用户**: 拥有私有NAS（飞牛OS）且希望统一管理多来源媒体资源的用户

## 2. 功能范围

### 2.1 网盘对接

| 网盘类型 | 对接方式 | 优先级 | 登录方式 |
|---------|---------|--------|---------|
| 飞牛OS云盘 | 官方API | P0 | Token认证 |
| WebDAV兼容网盘 | 标准WebDAV协议 | P0 | 用户名密码 |
| 115网盘 | API + 扫码 | P0 | 微信/支付宝扫码 |

### 2.2 分享链接削刮

支持以下网盘分享链接的削刮：

| 网盘 | 分享链接解析 | 削刮能力 | STRM生成 |
|------|-------------|---------|---------|
| 百度网盘 | 是 | 是 | 是 |
| 阿里云盘 | 是 | 是 | 是 |
| PikPak | 是 | 是 | 是 |
| 115网盘 | 是 | 是 | 是 |
| 夸克网盘 | 是 | 是 | 是 |
| 迅雷云盘 | 是 | 是 | 是 |

### 2.3 削刮数据源

| 数据源 | 用途 | 优先级 |
|--------|------|--------|
| TMDB | 电影/剧集元数据 | P0 |
| 豆瓣电影 | 中文标题/简介 | P1 |
| 本地STRM扫描 | 从已生成的STRM文件削刮 | P0 |

### 2.4 用户界面

| 页面 | 功能 |
|------|------|
| Dashboard面板 | 统计信息、快捷入口、存储状态 |
| 登录页 | 多平台网盘账号登录（支持115微信/支付宝扫码） |
| 媒体库首页 | 海报墙展示、分类筛选、搜索 |
| 添加链接页 | 批量添加分享链接 |
| 媒体详情页 | 查看媒体信息、转存状态、播放 |
| 播放页 | 视频播放（支持字幕、调速） |
| 设置页 | 网盘配置、削刮源配置、转存目录、清理设置 |

## 3. 需求详细描述

### 3.1 Dashboard面板

**用户故事**: 作为用户，我希望在面板首页看到媒体库统计和快捷操作入口，以便快速了解我的媒体库状态。

#### 验收标准

1. WHEN 用户登录成功，THEN 系统 SHALL 显示Dashboard面板
2. THEN 系统 SHALL 显示媒体库统计信息（电影数量、剧集数量、动漫数量、综艺数量）
3. THEN 系统 SHALL 显示当前网盘存储状态（已用空间、总空间）
4. THEN 系统 SHALL 显示快捷操作入口（添加链接、扫描STRM、手动整理）
5. THEN 系统 SHALL 显示最近添加的媒体列表
6. IF 网盘未配置，THEN 系统 SHALL 显示引导配置提示

### 3.2 115网盘扫码登录

**用户故事**: 作为用户，我希望使用微信或支付宝扫码登录115网盘，以便更方便地管理115资源。

#### 验收标准

1. WHEN 用户选择115网盘并点击扫码登录，THEN 系统 SHALL 显示二维码
2. WHEN 用户使用微信/支付宝扫描二维码并确认授权，THEN 系统 SHALL 获取登录凭证
3. IF 扫码超时（5分钟），THEN 系统 SHALL 提示用户重新扫码
4. IF 授权失败，THEN 系统 SHALL 显示错误原因并允许重试
5. THEN 系统 SHALL 保存登录凭证以便后续使用
6. IF 凭证过期，THEN 系统 SHALL 自动刷新或提示用户重新登录

### 3.3 转存目录配置

**用户故事**: 作为用户，我希望设置网盘转存的目标目录，以便整理我的媒体文件。

#### 验收标准

1. WHEN 用户进入设置页面，THEN 系统 SHALL 显示当前配置的转存目录
2. WHEN 用户修改转存目录，THEN 系统 SHALL 验证目录是否存在
3. IF 目录不存在，THEN 系统 SHALL 提示用户创建或选择其他目录
4. THEN 系统 SHALL 支持按媒体类型设置不同目录（电影/剧集/动漫/综艺）
5. THEN 系统 SHALL 保存配置并应用到后续转存操作

### 3.4 定时清理功能

**用户故事**: 作为用户，我希望设置定时清理转存目录，以便释放网盘空间。

#### 验收标准

1. WHEN 用户启用定时清理，THEN 系统 SHALL 显示清理设置选项
2. THEN 系统 SHALL 支持设置清理周期（每日/每周/每月）
3. THEN 系统 SHALL 支持设置清理时间（凌晨/中午/晚上）
4. THEN 系统 SHALL 支持设置保留最近N个文件
5. WHEN 清理任务执行，THEN 系统 SHALL 删除超出保留数量的最旧文件
6. THEN 系统 SHALL 记录清理日志供用户查看

### 3.5 安全码清理

**用户故事**: 作为用户，我希望一键清理115网盘的安全码，以便解决风控问题。

#### 验收标准

1. WHEN 用户点击清理安全码，THEN 系统 SHALL 自动访问115清理页面
2. THEN 系统 SHALL 显示清理进度和结果
3. IF 清理需要验证码，THEN 系统 SHALL 提示用户手动处理
4. THEN 系统 SHALL 记录清理时间以便用户了解清理频率

### 3.6 STRM文件自动生成

**用户故事**: 作为用户，我希望系统自动生成STRM文件保存到飞牛本地，以便Emby/Jellyfin直接读取播放。

#### 验收标准

1. WHEN 用户添加分享链接并削刮成功，THEN 系统 SHALL 自动生成STRM文件
2. THEN STRM文件 SHALL 保存到配置的转存目录
3. THEN STRM文件 SHALL 包含网盘文件的直接播放链接
4. THEN 文件命名 SHALL 按照「媒体类型/标题/年份/集数.strm」格式保存
5. IF 媒体是剧集，THEN 系统 SHALL 为每一集生成单独的STRM文件
6. THEN STRM文件 SHALL 支持中文路径编码

### 3.7 本地STRM文件削刮

**用户故事**: 作为用户，我希望系统扫描本地STRM文件并自动削刮海报墙，以便快速建立媒体库。

#### 验收标准

1. WHEN 用户点击扫描本地STRM，THEN 系统 SHALL 扫描配置的媒体目录
2. THEN 系统 SHALL 识别STRM文件内容获取网盘链接
3. THEN 系统 SHALL 从文件名提取媒体信息
4. THEN 系统 SHALL 调用削刮服务获取海报和元数据
5. IF 削刮失败，THEN 系统 SHALL 标记为待手动处理
6. THEN 系统 SHALL 更新数据库记录削刮结果

### 3.8 降低115风控

**用户故事**: 作为用户，我希望系统自动处理115网盘的风控问题，以便正常使用。

#### 验收标准

1. WHEN 系统检测到115风控提示，THEN 系统 SHALL 自动执行清理安全码操作
2. THEN 系统 SHALL 随机化请求间隔减少触发风控
3. THEN 系统 SHALL 自动处理简单的风控验证（如果可能）
4. IF 风控需要人工验证，THEN 系统 SHALL 提示用户手动处理
5. THEN 系统 SHALL 记录风控历史以便分析

### 3.9 自动分类

**用户故事**: 作为用户，我希望媒体自动分类到电影、电视剧、动漫、综艺，以便更好地管理媒体库。

#### 验收标准

1. WHEN 系统削刮媒体信息，THEN 系统 SHALL 自动识别媒体类型
2. THEN 系统 SHALL 将电影分类到「电影」目录
3. THEN 系统 SHALL 将电视剧分类到「剧集」目录
4. THEN 系统 SHALL 将动漫分类到「动漫」目录
5. THEN 系统 SHALL 将综艺分类到「综艺」目录
6. THEN 分类 SHALL 基于削刮数据的media_type字段

### 3.10 媒体数量统计

**用户故事**: 作为用户，我希望在面板看到各类媒体的数量统计，以便了解媒体库规模。

#### 验收标准

1. THEN 系统 SHALL 统计并显示电影总数
2. THEN 系统 SHALL 统计并显示电视剧总数
3. THEN 系统 SHALL 统计并显示动漫总数
4. THEN 系统 SHALL 统计并显示综艺总数
5. THEN 系统 SHALL 统计并显示已削刮数量和待处理数量
6. THEN 系统 SHALL 实时更新统计数据

## 4. 非功能性需求

### 4.1 性能

- Dashboard加载 < 1秒
- STRM文件生成单个 < 2秒
- 本地扫描1000个文件 < 30秒
- 削刮单个媒体 < 5秒

### 4.2 安全

- 115登录凭证加密存储
- 微信/支付宝扫码登录使用官方接口
- 不在日志中记录敏感信息

### 4.3 可靠性

- 115扫码登录支持超时重试
- 转存任务支持断点续传
- 清理任务执行前备份记录

## 5. 技术栈

| 层级 | 技术选型 |
|------|---------|
| 前端 | Vue3 + Vite + Ant Design Vue |
| 后端 | Python FastAPI + APScheduler |
| 数据库 | SQLite（轻量）/ PostgreSQL（可选） |
| 削刮服务 | TMDB API / 豆瓣API |
| 115登录 | 微信/支付宝开放平台API |
| 定时任务 | APScheduler |
| 容器化 | Docker + Docker Compose |
