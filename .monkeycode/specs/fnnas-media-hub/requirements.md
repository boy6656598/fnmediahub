# 需求文档 - fnnas-media-hub

## 1. 简介

**项目名称**: fnnas-media-hub  
**项目类型**: 私有云盘媒体中心管理系统  
**核心功能**: 登录网盘账号、添加分享链接、自动削刮海报墙、转存播放一体化  
**目标用户**: 拥有私有NAS（飞牛OS）且希望统一管理多来源媒体资源的用户

## 2. 功能范围

### 2.1 网盘对接

| 网盘类型 | 对接方式 | 优先级 |
|---------|---------|--------|
| 飞牛OS云盘 | 官方API（WebSocket/HTTP） | P0 |
| WebDAV兼容网盘 | 标准WebDAV协议 | P0 |

### 2.2 分享链接削刮

支持以下网盘分享链接的削刮：

| 网盘 | 分享链接解析 | 削刮能力 |
|------|-------------|---------|
| 百度网盘 | 是 | 是 |
| 阿里云盘 | 是 | 是 |
| PikPak | 是 | 是 |
| 115网盘 | 是 | 是 |
| 夸克网盘 | 是 | 是 |
| 迅雷云盘 | 是 | 是 |

### 2.3 削刮数据源

| 数据源 | 用途 | 优先级 |
|--------|------|--------|
| TMDB | 电影/剧集元数据 | P0 |
| 豆瓣电影 | 中文标题/简介 | P1 |
| 官方刮削器 | 阿里/PikPak官方 | P1 |

### 2.4 用户界面

| 页面 | 功能 |
|------|------|
| 登录页 | 网盘账号登录（飞牛OS / WebDAV） |
| 媒体库首页 | 海报墙展示、分类筛选、搜索 |
| 添加链接页 | 批量添加分享链接 |
| 削刮历史页 | 查看削刮结果、转存状态 |
| 播放页 | 视频播放（支持字幕、调速） |
| 设置页 | 网盘配置、削刮源配置 |

## 3. 需求详细描述

### 3.1 网盘登录

**用户故事**: 作为用户，我希望登录自己的网盘账号，以便访问和管理我的媒体文件。

#### 验收标准

1. WHEN 用户输入飞牛OS地址和凭据，THEN 系统 SHALL 验证并保存会话
2. WHEN 用户输入WebDAV地址、用户名和密码，THEN 系统 SHALL 验证连接并保存配置
3. IF 登录失败，THEN 系统 SHALL 显示错误信息并允许重试
4. WHILE 用户已登录，THEN 系统 SHALL 显示当前网盘状态和存储用量

### 3.2 添加分享链接

**用户故事**: 作为用户，我希望添加网盘分享链接，以便系统自动获取媒体信息。

#### 验收标准

1. WHEN 用户粘贴分享链接，THEN 系统 SHALL 自动解析链接类型
2. WHEN 用户批量粘贴多个链接（每行一个），THEN 系统 SHALL 依次解析
3. IF 链接已失效，THEN 系统 SHALL 标记为失败并显示原因
4. IF 链接格式不支持，THEN 系统 SHALL 提示用户并列出支持的类型

### 3.3 自动削刮海报墙

**用户故事**: 作为用户，我希望系统自动获取媒体的海报和信息，以便我直观地浏览我的媒体库。

#### 验收标准

1. WHEN 用户添加分享链接成功，THEN 系统 SHALL 自动从文件名提取关键词
2. WHEN 提取到关键词，THEN 系统 SHALL 调用TMDB/豆瓣API获取媒体信息
3. WHEN 获取到媒体信息，THEN 系统 SHALL 更新数据库并显示海报
4. IF 削刮失败，THEN 系统 SHALL 允许用户手动搜索或修正关键词
5. WHILE 削刮进行中，THEN 系统 SHALL 显示进度条和当前处理项

### 3.4 转存到网盘

**用户故事**: 作为用户，我希望点击播放时自动转存文件，以便我可以直接播放而无需手动操作。

#### 验收标准

1. WHEN 用户点击播放按钮，THEN 系统 SHALL 检查文件是否已转存
2. IF 文件已转存，THEN 系统 SHALL 直接播放
3. IF 文件未转存，THEN 系统 SHALL 显示"正在转存，请稍候..."
4. WHEN 转存完成，THEN 系统 SHALL 自动开始播放
5. IF 转存失败，THEN 系统 SHALL 显示错误并提供重试按钮
6. WHILE 转存进行中，THEN 系统 SHALL 显示进度百分比

### 3.5 媒体播放

**用户故事**: 作为用户，我希望在应用内直接播放视频，以便获得流畅的观看体验。

#### 验收标准

1. WHEN 视频开始播放，THEN 系统 SHALL 支持快进快退、音量调节
2. WHEN 视频有外挂字幕，THEN 系统 SHALL 自动加载并允许切换
3. WHEN 用户关闭播放器，THEN 系统 SHALL 记住播放位置
4. IF 播放卡顿，THEN 系统 SHALL 显示加载状态

## 4. 非功能性需求

### 4.1 性能

- 海报墙加载首批20个条目 < 2秒
- 削刮单个媒体 < 5秒
- 转存速度取决于网盘IO

### 4.2 安全

- 用户凭据加密存储
- 会话超时自动登出
- 不在日志中记录敏感信息

### 4.3 部署

- 支持Docker Compose一键部署
- 数据持久化到本地卷
- 配置通过环境变量或配置文件管理

## 5. 技术栈

| 层级 | 技术选型 |
|------|---------|
| 前端 | Vue3 + Vite + Ant Design Vue |
| 后端 | Python FastAPI |
| 数据库 | SQLite（轻量）/ PostgreSQL（可选） |
| 削刮服务 | TMDB API / 豆瓣API |
| 分享解析 | 各平台开放API/网页解析 |
| 视频播放 | DPlayer / Video.js |
| 容器化 | Docker + Docker Compose |
